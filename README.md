## Overview

Marola RP is a Brazilian FiveM roleplay ecosystem focused on community,
structured operations and immersive gameplay. This public repository documents
the project's direction and includes selected reference assets used to describe
the server environment.

> **Repository scope:** this is not the complete production server source. Some
> files under `build/` originate from the FiveM/CitizenFX runtime and retain their
> respective upstream licenses.

## Product pillars

- Brazilian roleplay identity and community
- Legal and illegal career systems
- Economy, properties, vehicles and progression
- Administration, moderation and audit workflows
- Discord communication and operational integrations
- Events and seasonal content
- Performance-conscious server architecture

## Architecture direction

```text
FiveM / CitizenFX
├── gameplay resources
├── economy and progression
├── administration and audit
├── Discord integrations
└── community-facing web experiences
```

The production ecosystem is developed across private repositories so operational
configuration, licensed assets, credentials and abuse-sensitive systems are not
published.

## Security and responsible disclosure

Do not publish exploits, private player data, credentials or production
configuration. Security concerns should be reported privately through the contact
channels on the official website.
